## 🎯 Latar Belakang
Keamanan data menjadi aspek krusial dalam sistem manajemen file berbasis web, khususnya terhadap ancaman **akses tidak sah, manipulasi data, dan kebocoran informasi**. Algoritma **RSA** sebagai salah satu algoritma kriptografi kunci publik dinilai mampu memberikan mekanisme pengamanan yang kuat melalui proses **enkripsi dan dekripsi berbasis pasangan kunci**.

Penelitian ini tidak hanya bersifat teoritis, tetapi juga **diimplementasikan secara nyata** dalam sebuah aplikasi web modern.
